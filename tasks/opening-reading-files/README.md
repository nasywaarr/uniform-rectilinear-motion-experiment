# 01 · Opening & Reading Files

Uniform rectilinear motion (MRU) experiment: read data from a text file, store it in a dictionary,
modify and rewrite it, then compute the average velocity with its propagated error.

## Files
- `opening_reading_files.py` – the solution
- `esperimento_mru_or.txt` – original data (never modified)
- `esperimento_mru.txt` – working copy the script reads/rewrites

## Run
```bash
cp esperimento_mru_or.txt esperimento_mru.txt   # reset the working copy
python opening_reading_files.py
```
